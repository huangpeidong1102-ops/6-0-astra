# 按需使用的强化模型与机理写作

只在实际进行定量强化讨论、计算、核算或相关段落修改时读取。一般引言、摘要、语言润色或定性讨论不要求完成本页全部计算。公式整理自课题组范例，帮助选择论证工具；当前论文采用哪些模型由当前材料、组织与数据决定。

P1–P8的完整出处见[来源索引](nature-storyboarding.md#source-index)，下文页码为PDF页码。参数表记录“范例采用值”，不是任意高熵合金的默认值。正式计算前核对适用模型的原始来源和当前输入。

## 1. 按问题选择模型

| 待解释的问题 | 可选工具 | 启用条件 |
|---|---|---|
| 晶粒变化对屈服的贡献 | Hall–Petch | 有定义明确的晶粒尺寸与适用的系数 |
| 析出相阻碍滑移 | 相内切过/绕过比较，必要时再相加权 | 有相身份、尺寸、相内体积分数和物理参数 |
| 异质组织的力学贡献 | LUR估算HDI应力 | 有相应回线、屈服点判据与流动应力 |
| 形成何种相 | 相形成经验量与相图 | 成分及对应元素/二元参数；与组织证据联用 |
| 氧化速率随温度变化 | 抛物线/Arrhenius拟合 | 质量、面积、时间、温度及选定拟合区间 |

P6–P8主要用变形观察解释位错与界面作用，并未给出完整MPa贡献分解。沿用这种定性论证完全可行，不因存在位错、相界或析出物就自动生成贡献数值。

## 2. 样本中的屈服分解与相加权

P1第10页式(7)、P2第8页式(1)、P4第8页式(1)采用：

\[
\sigma_y=\sigma_0+\Delta\sigma_p+\Delta\sigma_G.
\]

这里的三项分别为所用摩擦基线、析出贡献和晶界贡献。该分解是这些论文的建模选择，不能作为所有材料唯一的屈服组成式。

P1第10页式(8)、P2第8页式(2)估算：

\[
\sigma_0=\sum_i c_i\sigma_i,\qquad \sum_i c_i=1.
\]

`c_i`为0–1原子分数；不要把17 at.%直接作为17代入。原文元素摩擦应力为Al 16、Cr 454、Fe 100、Ni 22 MPa（P1表5；P2表2，引用Sriharitha等，J. Alloys Compd. 583 (2014), 419–426）。这种加权基线不能改名为独立固溶强化后再加一次。

P4借用 `σ₀ = 165 MPa`（第8页，文献[46]：He等，Acta Mater. 102 (2016), 187–196）；这是论文采用的假设，不能直接迁移成新成分的常数。

P1第11页式(9)、P2第9页式(3)、P4第8页式(2)使用相加权：

\[
\Delta\sigma_p=F_{\mathrm{FCC}}\Delta\sigma_{\mathrm{FCC}}
+F_{\mathrm{BCC}}\Delta\sigma_{\mathrm{BCC}}.
\]

本页以大写 `F` 表示宏观基体相分数，避免与下面的相内析出物分数 `f` 混淆；这是对原文符号的统一。相加权本身是模型假设，不等于已经计算全部相间应变分配。

## 3. Hall–Petch

P1第12页式(14)、P2第9页式(7)、P4第10页式(7)：

\[
\Delta\sigma_G=k\,d^{-1/2}.
\]

`d`为该模型定义的晶粒尺寸。若 `k` 采用MPa·μm¹ᐟ²，则 `d`用μm，输出MPa。范例采用约226 MPa·μm¹ᐟ²；从其他合金或温度借用时，应有明确来源和适用理由。晶粒尺寸、片层宽度和析出物间距分别对应不同物理尺度，不直接替换。

## 4. Orowan绕过与颗粒间距

P1第11页式(10)、P4第8页式(3)：

\[
\Delta\sigma_{\mathrm{Or}}=
M\frac{0.4Gb}{\pi\sqrt{1-\nu}}
\frac{\ln(2r_m/b)}{\lambda_p},
\quad r_m=\sqrt{\frac{2}{3}}r,
\quad \lambda_p=2r_m\left(\sqrt{\frac{\pi}{4f}}-1\right).
\]

`M`：Taylor因子；`G`：基体剪切模量；`b`：滑移位错的Burgers矢量模；`ν`：泊松比；`r`：平均颗粒半径；`f`：该基体内的析出物体积分数；`λp`：所用几何近似下的颗粒间距。

计算可统一为 `G`用Pa、`b/r/λp`用m，结果由Pa转MPa。确认粒径是半径或直径、间距为正，且所用颗粒分布/体积分数符合间距近似；不把图中模糊的 `size` 自动解释成半径。

## 5. 共格、模量失配与有序强化

P1第11–12页式(11–13)、P2第9页式(4–6)、P4第9页式(4–6)：

\[
\Delta\sigma_{\mathrm{CS}}=M\alpha_\varepsilon(G|\varepsilon_c|)^{3/2}
\left(\frac{rf}{0.5Gb}\right)^{1/2},
\]
\[
\Delta\sigma_{\mathrm{MS}}=0.0055M(\Delta G)^{3/2}
\left(\frac{2f}{G}\right)^{1/2}
\left(\frac{r}{b}\right)^{3m/2-1},
\]
\[
\Delta\sigma_{\mathrm{OS}}=0.81M\frac{\gamma_{\mathrm{APB}}}{2b}
\left(\frac{3\pi f}{8}\right)^{1/2}.
\]

其中 `εc = (2/3)ε`；`ε = Δa/a`，CS式使用失配幅值 `|εc|`，显式写出原文正值参数所隐含的幅值约定；`ΔG = |G − Gp|`；`Gp`为析出相剪切模量；`γAPB`为反相畴界能；`αε`和小写`m`为模型系数。`γAPB`用J·m⁻²；不要将mJ·m⁻²的数值直接代入SI公式。

这些范例采用以下切过组合，再与绕过临界强度比较：

\[
\Delta\sigma_{\mathrm{shear}}
=\max(\Delta\sigma_{\mathrm{CS}}+\Delta\sigma_{\mathrm{MS}},\Delta\sigma_{\mathrm{OS}}),
\qquad
\Delta\sigma_{\mathrm{precipitate}}
=\min(\Delta\sigma_{\mathrm{shear}},\Delta\sigma_{\mathrm{Or}}).
\]

在适用机制可竞争的条件下使用此组合；不要将CS、MS、OS、Orowan四项全部相加。P1/P2对B2析出物略去OS是其具体处理，不能推广为“所有B2都没有有序强化”。

## 7. HDI：与回线和应变状态对应

P3第4–5页给出无编号公式，见第6页Fig. 8：

\[
\sigma_{\mathrm{HDI}}=\frac{\sigma_u+\sigma_r}{2},
\qquad \sigma_{\mathrm{eff}}=\sigma_{\mathrm{flow}}-\sigma_{\mathrm{HDI}}.
\]

按实际LUR方法定义卸载/再加载屈服点、符号、偏移判据与测量应变。报告比例时写清分母，例如 `σHDI/σflow`；P3图文对分母有不一致，不直接复制其百分数。

KAM与异质变形图像可以支持机制讨论，有LUR数据时才按此方法定量HDI。该应力分解与障碍强化模型不是天然互不重叠的项，不默认再将HDI与所有析出、晶界、位错项相加。

## 8. 可选相形成参数：服务设计解释

P5第8–9页式(2–6)、P6第5页式(1–6)、P7第4–5页式(1–6)、P8第7页式(1–6)讨论以下经验量；P5未列电负性差公式。

| 参数 | 规范化表达 | 单位/定义 |
|---|---|---|
| 混合熵 | `ΔSmix = −R Σci ln ci` | `R = 8.314 J·mol⁻¹·K⁻¹`；原子分数和为1 |
| 混合焓 | `ΔHmix = 4 Σ(i<j) ΔHij ci cj` | 每一元素对计一次；说明二元等原子焓定义 |
| 价电子浓度 | `VEC = Σci VECi` | 保留各元素参数来源 |
| 原子尺寸差 | `δ = [Σci(1−ri/r̄)²]¹ᐟ²`，`r̄ = Σci ri` | 无量纲；以百分数报告时乘100% |
| 熵焓比 | `Ω = Tm ΔSmix / |ΔHmix|` | `Tm = Σci Tm,i`，用K；能量单位一致 |
| 电负性差 | `Δχ = [Σci(χi−χ̄)²]¹ᐟ²`，`χ̄ = Σciχi` | 保留所用电负性标度 |

这些量用于解释相形成趋势，不是以MPa表示的屈服强化项，也不替代衍射/显微物相证据。不同物理意义的失配量分别命名，不将原子尺寸差`δ`等同于界面晶格失配。

## 9. 可选氧化模型

P5第3页式(1)：`(ΔW/A)² = kp t`。原文单位为ΔW：mg，A：cm²，t：h，故 `kp`为mg²·cm⁻⁴·h⁻¹。拟合对象是单位面积增重的平方；使用实际时间窗及截距处理，不自动将全时段认定为单一抛物线规律。

P5第10页式(7)：`kp = k0 exp(−Ea/RT)`，即 `ln kp = ln k0 − Ea/(RT)`。T用K；`ln kp`对`1/T`的斜率为 `−Ea/R`。若横轴为`1000/T`，相应换算斜率；不能把斜率直接写成活化能。

用相同温度、时间与表面状态下的增重、速率及氧化层完整性比较抗氧化表现。活化能是温度依赖的拟合参数，不能单独代表任意温度下性能更好。

## 10. 把计算写成Discussion

推荐顺序：所解释的性能差异→模型及选择理由→当前样品输入→主要计算结果→与实验差异的联系→组织设计含义。公式不应淹没中心发现，重复参数可放表中。

> The contribution of [mechanism] was estimated using [model], with [measured inputs]. The calculated increment changes from [a] to [b] MPa following [treatment], accounting for [defined part] of the measured strength increase. This result links [specific structural change] to [mechanical response].

内部检查：统一单位；追溯测量值/文献值/拟合值；区分模型预测与实验残差反推；避免重复计数；若输入不确定性影响结论，再做敏感性或误差分析。没有误差数据时不编造置信区间。实质差异在正文准确说明，常规校验不变成每段的退让句。

若用户要求“先写能完成的计算，最后列缺项”，正文集中呈现已完成的估算、比较及其物理含义；尚未计算的另一机制、缺失参数和未开展的试验放在末尾作者备注，不在正文再重复一遍。已算结果与实测值的剩余差额可以描述为未分配贡献，不能据残差直接指定另一机制；若正文不讨论残差归属，也无需额外插入一串排除性声明。这不改变对真正影响已写结论的模型假设或局限的正常交代。

样本未给出完整独立的Taylor位错强化或固溶强化计算范式。用户的新研究需要时，可扩展合适模型并核对原始文献、参数和适用条件；`Taylor factor`的出现本身不等于已经计算Taylor位错强化。不要为填满强化表而补造缺失机制。
